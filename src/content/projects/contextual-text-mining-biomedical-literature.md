# Contextual Text Mining from the Biomedical Scientific Literature

This project develops text mining techniques to automatically extract biologically important information, such as relationships between biomolecules, from scientific publications.

**Keywords:** Text Mining, Bioinformatics, Information Extraction

**Funding:** European Commission, FP7 Marie Curie Career Integration Grant (2012-2016)
